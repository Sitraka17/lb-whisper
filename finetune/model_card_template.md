# whisper-large-v3-turbo-lb

Whisper large-v3-turbo fine-tuned with LoRA on Luxembourgish (Lëtzebuergesch), trained only on
FLEURS `lb_lu` (CC-BY-4.0, __H_TRAIN__ h of read speech). Recipe, configuration and evaluation
scripts: <https://github.com/Sitraka17/lb-whisper>.

What this model offers is a reproducible recipe on a small amount of open data, a robustness test
on low-bitrate Opus audio, and a model that the companion meeting-notes app can run locally.

### Comparison with other models

All models are scored on the same audio, the same references and the same normaliser
(`finetune/lb_text.py`: HTML entities unescaped, case and punctuation dropped, apostrophes and hyphens
inside words kept). The subset is the first __N_SUBSET__ utterances of the test split, which hold
__N_SUBSET_DISTINCT__ distinct sentences (FLEURS records each sentence with several speakers).

__BENCH_TABLE__

- "Opus 16 kbit/s" is the WhatsApp condition: each clip is re-encoded with ffmpeg as 16 kbit/s mono
  Opus, then decoded back to 16 kHz PCM. Same text, lower audio quality.
- WER counts substitutions, deletions and insertions against the number of reference words, so a
  model that outputs more words than the reference (repetitions, hallucinated text, another language)
  can exceed 100 %.
- Speed is wall-clock seconds per minute of audio on the clean condition, on one GPU: batches of 16
  with Transformers, one clip at a time with faster-whisper. It depends on the backend and is only a
  rough guide.

Caveats: according to their model cards, the uni.lu model was trained on about 150 h and the ZLS
model on about 75 h of Luxembourgish; whether that data overlaps with the FLEURS sentences is unknown. The ZLS model is published only in CTranslate2 format
and was decoded with faster-whisper (float16, greedy, no VAD), the others with Transformers (greedy).
Treat the comparison as indicative.

Every number above is regenerated by `finetune/benchmark.py`, `finetune/evaluate.py` and
`finetune/fill_card.py`.

## Usage

### Transformers

```python
from transformers import pipeline

asr = pipeline("automatic-speech-recognition", model="SitrakaForler/whisper-large-v3-turbo-lb", chunk_length_s=30)
out = asr("meeting.wav", return_timestamps=True, generate_kwargs={"language": "lb", "task": "transcribe"})
print(out["text"])
```

### faster-whisper (CTranslate2 int8 export)

```python
from faster_whisper import WhisperModel

model = WhisperModel("SitrakaForler/whisper-large-v3-turbo-lb-ct2", device="cpu", compute_type="int8")
segments, info = model.transcribe("meeting.wav", language="lb", vad_filter=True)
for s in segments:
    print(f"[{s.start:.1f}-{s.end:.1f}] {s.text}")
```

The WER of the int8 export was not measured separately; the figures above are for this
Transformers model. VAD was not used in the benchmark.

## Limitations

- Trained on __H_TRAIN__ h of read speech: Wikipedia sentences read aloud one at a time.
- Not evaluated on spontaneous speech, meetings, overlapping speakers, code-switching
  (Luxembourgish with French, German or English in the same sentence) or speech by minors.
- Dialectal variation and the *Eifeler Regel* (n-deletion) are learnt only as far as FLEURS shows them.
- Numbers, dates and proper nouns follow the written conventions of the FLEURS sentences.
- Evaluated on one test set. Run `finetune/benchmark.py` on your own audio before relying on it.
